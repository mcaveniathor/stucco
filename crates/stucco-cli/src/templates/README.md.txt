# {{title}}

A [stucco](https://github.com/mcaveniathor/stucco) app.

```sh
cargo run
```

Then open http://127.0.0.1:3000. The app is in `src/main.rs`: a shared
layout, a home page and a table of tasks. The guide's recipes show the next
steps, such as forms, filtered tables and partial updates:
https://mcaveniathor.github.io/stucco/guide/recipes.html
